The evidence model

Confidence is classified, never a number.

● confirmed

A resolved structural link — a call to a declared or imported symbol.

● possible

Plausible but unproven. A name match, an unattributable member call.

● unknown

Resolution was blocked. Says nothing about whether a link exists.

Tests keep four honest states — passed · failed · not executed · unavailable. Never an implied pass.
Honesty engine

"We can't see that from here" — as a feature.

Unknowns

Behavior not verified: an untested public symbol, an unresolved call, tests not run.

Blind spots

Inputs not analyzed: other languages, dynamic dispatch, eval(), binary & generated files.

An analysis is never called "complete" while relevant inputs were skipped.
Safety, by contract

Trust is enforced in code.

Read-only

Never touches your source. Writes only a disposable cache.

No shell

Tests run via an argv array — a filename is just a filename.

Consent

Nothing executes unless you pass --run-tests.

Offline + redacted

No network; secrets & paths redacted from reports.
